What each failure mode looks like

  • Mixed content block: only if you target a non-loopback HTTP URL (e.g. http://192.168.x.x) from this HTTPS page. Loopback (localhost/127.0.0.1) is a secure origin, so it is allowed.
  • CORS failure: the server didn't return Access-Control-Allow-Origin for this origin. Network error with a CORS message in DevTools.
  • LNA denied/prompt (Chrome 142+): a TypeError: Failed to fetch while the LNA pill reads prompt/denied. Firefox/Safari show no prompt — just CORS + mixed content.
