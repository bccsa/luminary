Hardware Bridge — running

● Local API listening on http://127.0.0.1:…
CORS allow-list: see ALLOWED_ORIGINS env (default * = dev only).

Endpoints

GET /api/ping — health check
GET /api/system — real local machine info (CPU, mem, uptime)
GET /api/device — current virtual device state
POST /api/device — set device state { on, label, brightness }

From an HTTPS page, call http://localhost:…/api/*. Chrome 142+ will show a Local Network Access permission prompt on first call.

Closing this window keeps the service running in the background.
